Hover a host and click the **folder** icon to open a dual-pane **local ↔ remote** browser.

## Transfers

- Upload and download whole folders with **progress and cancel**.
- Shellport asks before overwriting local files.
- **Drag and drop** files from your desktop file manager to upload them.

## Remote file operations

Create folders, rename, change permissions (**chmod**) and delete on the server.

## Safety

Downloads never write outside the folder you choose and never follow symlinks, even if a server sends hostile file names.
