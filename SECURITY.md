# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately via
[GitHub security advisories](https://github.com/EarvinInk/shellport/security/advisories/new)
("Report a vulnerability" under the Security tab).

Include what you found, how to reproduce it, and which version you tested. You'll get a reply as soon as possible, and a fix will be released before the details are made public.

## Supported versions

Security fixes go into the latest release. Please update to it before reporting.
